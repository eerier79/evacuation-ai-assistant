## What I did myself
- Chose the topic and the idea: an evacuation assistant that combines course topics.
- Chose the final set of four algorithms (HMM, Bayes' theorem, A* search, MDP) from topics practiced in the course.
- Drew the Kitty character used in the interface (`assets/kitty.jpg`); chose the design direction and the gamification idea.
- Decided which improvements to make (POMDP, learning from data, Q-learning, robustness tests, You vs AI, map editor).
- Set up the environment, ran the program, the tests and the web interface on my own computer, and own the GitHub repository.
- Reviewed the results and prepared to explain every algorithm and every file in the defense.
